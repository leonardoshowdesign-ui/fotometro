# Fotômetro de Palco

App para iluminadores aferirem a luz de fotografia e TV com o celular: escolhe os aparelhos, calcula zoom, intensidade e cor, gera o plugin da grandMA2 e guia a medição no palco, com câmera ao vivo e contagem automática.

Aberto em: https://leonardoshowdesign-ui.github.io/fotometro/
